# Operation Opening Day review gallery

The gallery uses actual game frames at the GitHub Pages subpath in portrait software browsers. Territory pairs use migration seed 7, with the Phase 09 build on the left and Opening Day on the right. The captures are near the midpoint of each territory from guided accelerated offline runs. Minor frame timing differences remain. The filming environment provides software rendering, so the sharpness and frame pacing are separate from native iPhone acceptance.
