# Phase 05 targeted visual evidence

These are real gameplay-camera captures from built applications served under `/Retriever-Run/`. Seeded controls let the same obstacle, dog pose or wildlife encounter appear across runs. The moving clips use the browser's animation clock at a 320 × 568 CSS viewport. Linux software rendering can slow playback. Visibility uses elapsed game time and excludes gaps between clear samples.
