# Retriever Run 1.0 release notes draft

Run the Great Migration through fifteen North American habitats, from Gulf Coast Marsh to the Canadian Mountain Wilderness. Duck and jump through changing terrain, retrieve birds and build your career hunt by hunt.

- The Field Journal now has real wildlife photography for every species, with identification notes and a larger offline portrait. Find new species during hunts to fill your observation and retrieve records.
- Look for denser coastal grass beds, darker marsh channels, willow-covered banks, prairie grass and rocky snow-covered trail margins.
- Worldwide has one standings table. Verified score determines the official rank, and each hunter's independent bests are shown across five columns. Public competition opens after hosted verification and the launch review.
- Your retriever, equipment, Lodge, records and career are available for offline play. Export a private local snapshot under Field settings → Game and installation.
- On iPhone, use Safari’s Share menu and Add to Home Screen to use the Boyd app icon. Installing is optional. You can start a hunt directly in Safari.

Manage game content under Field settings. If a download is interrupted, use Retry download to resume with already verified files. Apply updates between hunts. Worldwide membership is optional. Keep local-save exports private. Report issues with the in-game build number, browser and device type. [Project issues](https://github.com/bladunk/Retriever-Run/issues)
